# 🦅 Animated Image Slider & Showcase

A modern, responsive, and beautifully animated image slider built with **HTML5**, **CSS3**, and **Vanilla JavaScript**. Featuring smooth sliding transitions, background preview cards, an automatic progression timer bar, and fully customizable content blocks.

---

## ✨ Features

- **Smooth Stacking Transitions:** Unique multi-layered slider effect where active slides transition seamlessly into the background thumbnails.
- **Auto-Play with Progress Bar:** Dynamic animated timer bar tracking the auto-advance duration (synced with JavaScript timeouts).
- **Responsive Design:** Fully optimized layout for desktops, tablets, and mobile screens.
- **Interactive Controls:** Next/Previous navigation buttons with hover micro-interactions.
- **Clean Vanilla Stack:** No heavy frameworks or external dependencies required—just pure HTML, CSS, and JS.
